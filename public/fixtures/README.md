# Development fixtures

Real photos of La Casa de Susana's listings, taken from the legacy site (lacasadesusana.es, Oct 2026 uploads).
They are only served when `NUXT_VESTTA_API_KEY` is not set (local development / design review).
With the key set, every listing and image comes from the Vestta public catalogue.
Delete this folder once the Vestta key is configured in every environment.
